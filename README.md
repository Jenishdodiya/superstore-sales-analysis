# Superstore Sales Data Analysis

An end-to-end sales data analysis project using Microsoft Excel and Power BI. The project focuses on data quality, exploratory analysis, KPI development, and dashboard-based business insights.

## 📊 Project Overview

This project analyzes a Superstore sales dataset containing 9,800 sales records and 18 original columns.

The analysis explores:

- Sales performance over time
- Category and sub-category performance
- Regional sales performance
- Customer segment contribution
- Shipping mode distribution
- Top-performing products
- Key sales KPIs

## 🎯 Business Objectives

The main objectives of this project were to:

- Validate and prepare the sales data for analysis
- Identify important sales trends and patterns
- Measure overall sales and order performance
- Compare sales across categories, regions, and customer segments
- Identify the top-selling products
- Build dashboards that communicate the findings clearly

## 🛠️ Tools Used

- Microsoft Excel
- Power BI
- DAX

## 🧹 Data Preparation

The dataset was reviewed and prepared before analysis.

Key data preparation activities included:

- Row and column validation
- Missing-value checks
- Duplicate-row verification
- Date validation
- Sales-value validation
- Creation of calculated columns
- Formatting and structuring data for analysis

## 🔎 Exploratory Data Analysis

The analysis covers:

### Sales Trend
Sales were analyzed across different years to understand changes in overall sales performance.

### Category Analysis
Sales were compared across product categories to understand category-level contribution.

### Regional Analysis
Sales were analyzed across regions to identify differences in regional performance.

### Customer Segment Analysis
Sales were compared across customer segments to understand their contribution to overall sales.

### Ship Mode Analysis
Different shipping modes were analyzed to understand their sales contribution.

### Top 10 Products
The top 10 products were identified based on total sales.

## 📊 Power BI Dashboard

An interactive Power BI dashboard was created containing:

- Total Sales KPI
- Total Orders KPI
- Total Customers KPI
- Average Order Value KPI
- Sales Trend by Year
- Sales by Category
- Sales by Region
- Sales by Customer Segment
- Sales by Ship Mode
- Top 10 Products by Sales
